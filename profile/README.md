<h1 align="center">Hallume</h1>

<p align="center"><strong>A halo of light for the modern web.</strong><br/>
Premium, original UI templates, WebGL heroes, shader effects and interactive components. Download, adapt, ship.</p>

---

### ✨ What we make
- **Cinematic heroes:** WebGL and particle scenes that react to the pointer
- **Scroll-driven landings:** product stories told through motion
- **Glass-style dashboards:** translucent, luminous interface kits
- **Interactive components:** configurable sliders, carousels and pointer-physics UI
- **Textures:** ASCII, dither and halftone effects with live in-browser editors that export code

### 🧭 Principles
- **Original by design:** every concept, visual and line of code is our own
- **Fast and accessible:** 60fps targets, mobile fallbacks, `prefers-reduced-motion` respected
- **Production-ready:** clean code, clear docs and live demos for every piece

The first drops are in the works. Watch this org to see them land.
